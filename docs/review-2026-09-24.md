# Code review: issues and fixes (2026-09-24)

Scope: the whole fork at `cam_wip` `bd0b72b` — the C++ data driver, readback
node, `smartmicro_processing`, the view scripts, the RViz panels,
`umrr_ros2_msgs`, `smartmicro_description`, Docker and CI. Items already
tracked in [ROS 2 driver improvements](ros2-improvements.md) are not repeated
unless the review found a specific defect beyond them.

Each item has an ID used in commit messages. **Status** is updated as fixes
land: `open`, `fixed`, `partial` (with a note), or `deferred` (with a reason).
**Origin**: `upstream` means inherited from smartmicro; `fork` means
introduced on this fork.
